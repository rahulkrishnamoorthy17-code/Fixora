# Fixora Final Structure

## Public navigation
- Home (dropdown: Home 1, Home 2)
- About
- How It Works
- Testimonials
- Services
- Pricing
- Blog
- Contact

## Authentication
- Signed out: Sign In + Sign Up in the navbar.
- Signed in: those controls are replaced by a Profile menu.
- Profile menu contains My Dashboard, Repair History, Account Settings and Sign Out.
- Customer Dashboard is not a separate public navigation item and redirects to Sign In when accessed without a session.

## UI controls
- Light/Dark mode toggle
- RTL/LTR direction toggle with direction icon and clear label
- Responsive offcanvas navigation below extra-large desktop widths

## Footer
Compact footer with the same Fixora brand mark/name as the navbar, essential quick links, core services and contact information only.
